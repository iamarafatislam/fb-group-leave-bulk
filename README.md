# FB Group Leave (Bulk) 🚀

> A clean, lightweight Chrome extension to scan and bulk-leave Facebook groups at an adjustable, safe pace.

---

## ✨ Features

- **⚡ Group Discovery**: Automatically connects to your active Facebook session to retrieve your joined groups.
- **🎯 Bulk Selection**: Select all, clear selection, or manually pick individual groups.
- **🔍 Instant Filter**: Filter through your groups in real time by name.
- **⏱️ Adjustable Speed Pacing**: Choose from Ultra (1.5s), Fast (2.5s), Normal (4.0s), or Safe (6.0s).
- **📊 Real-time Progress Tracking**: Live progress bar, ETA calculation, and a Stop button.
- **🔒 Local & Private**: Runs directly in your browser with zero external servers.

---

## 📥 How to Install

1. Open Google Chrome and go to `chrome://extensions/`
2. Turn on **Developer mode** (top-right toggle).
3. Click **Load unpacked** (top-left).
4. Select the `fb-group-leaver` folder.
5. Open Facebook in any tab and click the extension icon to launch the side panel!
